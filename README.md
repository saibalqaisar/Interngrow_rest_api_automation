 Task 4: REST API & Automation

Python automation project built during the InternGrow internship.

## Features
- Consume public REST APIs (Open-Meteo, Hacker News)
- Parse JSON data
- Web scraping with BeautifulSoup
- Email automation with smtplib
- Scheduled daily report with schedule
- API error handling, retries and logging

## Setup
pip install -r requirements.txt
copy .env.example to .env and add your details
python main.py
